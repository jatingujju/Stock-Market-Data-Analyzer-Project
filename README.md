# 📈 Stock Market Data Analyzer

A Python-based application for analyzing stock market data, visualizing price movements, and exploring market trends through an interactive dashboard.

## 🚀 Project Overview

The Stock Market Data Analyzer uses financial market data to help users explore stock performance, analyze historical prices, and visualize market trends. Built with Python and Streamlit, it provides an interactive interface for stock market analysis.

## ✨ Features

- Fetch stock market data using Yahoo Finance
- Analyze historical stock prices
- Visualize stock price trends interactively
- Explore financial data using charts and graphs
- Analyze market performance using technical indicators
- Interactive dashboard built with Streamlit
- Data visualization using Plotly

## 🛠️ Technologies Used

- Python
- Streamlit
- yfinance
- Pandas
- NumPy
- Plotly

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

Navigate to the project folder:

```bash
cd YOUR_REPOSITORY_NAME
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run dashboard.py
```

The application will open in your browser.
